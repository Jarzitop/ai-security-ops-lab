# Detections

Detections belong here only after they have been implemented and validated in the lab.

Each detection should document:

1. objective;
2. data source;
3. logic;
4. validation procedure;
5. observed events;
6. MITRE ATT&CK mapping when justified;
7. false positives;
8. tuning decisions;
9. limitations.
