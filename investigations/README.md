# Investigations

This directory contains completed SOC-style investigations from controlled lab activity.

Each investigation should include:

1. alert summary;
2. initial triage;
3. evidence;
4. timeline;
5. affected entities;
6. relevant processes/users/network activity;
7. ATT&CK mapping when supported;
8. analysis;
9. verdict;
10. severity;
11. recommended response;
12. investigation notes.

Possible verdicts include benign, false positive, suspicious, malicious, or inconclusive.

The evidence must support the verdict.
