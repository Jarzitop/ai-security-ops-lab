# Architecture v1 — Historical

Status: **SUPERSEDED by [v2.md](v2.md)**

This document preserves the project's first SOC-focused architecture for design history. It is not the current target architecture.

## Original design goal

Build a SOC lab that fits an 8 GB Windows laptop without running the Wazuh central stack locally.

## Logical architecture

```text
                           Internet
                              |
                   +----------------------+
                   | Remote Wazuh server  |
                   | Linux                |
                   | Server + Indexer +   |
                   | Dashboard            |
                   +----------+-----------+
                              |
              Wazuh agent telemetry / enrollment
                              |
          +-------------------+-------------------+
          |                                       |
+---------+----------+                  +---------+----------+
| Windows 11 host    |                  | Future Linux VM    |
| Sysmon             |                  | Ubuntu Server      |
| Windows Event Logs |                  | Wazuh Agent        |
| Wazuh Agent        |                  | SSH/auth logs      |
+--------------------+                  +--------------------+
                                                   ^
                                                   |
                                      controlled local traffic
                                                   |
                                          +--------+-------+
                                          | Kali Linux VM  |
                                          | existing VM    |
                                          +----------------+
```

## Resource strategy

### Host — Windows 11

Intended as the first endpoint for safe telemetry generation.

Planned:
- Sysmon;
- Windows Event Logs;
- Wazuh Agent.

Destructive or high-risk simulations are excluded from the physical host.

### Kali VM

Existing VM intended for controlled network activity and later authorized simulation against lab-only targets.

### Future Ubuntu Server VM

Originally proposed as a lightweight isolated Linux endpoint for SSH/authentication, sudo, process, and service telemetry.

### Remote Wazuh central components

Wazuh Server, Indexer, and Dashboard were intentionally placed outside the laptop because the documented host memory is insufficient for a sensible local all-in-one deployment.

## Why v1 was superseded

The project scope was expanded from a conventional SOC/Wazuh lab into an AI-Augmented Security Operations Lab. The infrastructure assumptions remain useful, but the active architecture now includes detection engineering, structured investigations, an AI analyst layer, evaluation, and AI-security testing.
