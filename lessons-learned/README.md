# Lessons Learned

This directory records technical decisions, troubleshooting, limitations, and changes in understanding during the project.

Useful entries should explain:

- what failed;
- what evidence revealed the cause;
- how the issue was fixed;
- what would be done differently in a production environment;
- what remains unresolved.

Troubleshooting is part of the portfolio evidence when it demonstrates reasoning rather than trial-and-error.
